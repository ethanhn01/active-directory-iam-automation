# Active Directory IAM Automation Lab

A PowerShell-based cybersecurity project demonstrating
Identity and Access Management (IAM) automation.

## Project Objectives

- Automate employee onboarding
- Automate employee offboarding
- Implement Role-Based Access Control (RBAC)
- Apply least-privilege access principles
- Generate user access audit reports

## Technologies

- PowerShell
- Active Directory (optional isolated lab)
- GitHub Actions
- CSV and JSON

## Lab Environment

This project uses a fictional company called DemoCorp.

The initial implementation uses a simulated directory
to safely test IAM processes without a domain controller.
